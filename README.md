# Build Starter

### Build locally

```bash
mvn clean install
```

This installs the starter into your local Maven repository.

# Usage

Add the dependency to your project's `pom.xml`:

```xml
<dependency>
    <groupId>ke.meliora</groupId>
    <artifactId>mulika-starter</artifactId>
    <version>1.0.0</version>
</dependency>
```
